# Beyond The Wall — Android

Android WebView wrapper for the uploaded ODM Prototype 0.1 HTML game.

## Add the game project
Upload the file `Beyond-The-Wall-Android-Project.zip` to the repository root. The GitHub Actions workflow extracts it and builds the APK.

## Build
Open **Actions** → **Build Beyond The Wall APK** → **Run workflow**.
When the run completes, download the `BeyondTheWall-APK` artifact.
